# Descriptions

d20 physical description tables for zeros, adapted from the BRP-ORC Distinctive Features option, with the wording drawn from Robert E. Howard's Conan stories.

Every zero gets two features from two different categories of its sex's set: roll 1d10 for a category, rerolling a category already used, then 1d20 within it.
